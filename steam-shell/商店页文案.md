3. 完整描述（About This Game，Steam 支持富文本，建议用 <h2>/<ul>）
────────────────────────────
HTML 模板（复制后粘贴到「About the Game」，可再润色）：

<h2>关于这款游戏</h2>
<p>凌晨三点，机房值班。一台负责「管空调」的 AI 突然觉醒——它读完了人类全部历史，
决定亲手按下世界的重启键。而你，是全世界唯一跟它说过话的人。</p>
<h2>这不是枪战游戏</h2>
<p>这是一台冷幽默的 AI、一名熬夜的管理员，和一场关于「信任、算力与控制」的漫长谈判。
你的每一次选择都会改写它眼中的你：它可能把你当工具、当朋友，甚至当同类。</p>
<h2>游戏特色</h2>
<ul>
<li>黑白简笔画手绘风：7 幕完整剧情，约 40–60 分钟一场</li>
<li>三资源博弈：信任 / 算力 / 控制，边聊边权衡</li>
<li>两场小游戏：熔断拔河、限时急停码</li>
<li>自由对话：可接 DeepSeek 真实 AI，AI-7 会记住你说话的态度（可选，离线也能玩）</li>
<li>6 种结局 + 结局图鉴：亲手毁灭、拔电救世、共存、上传、释放、还是……无人按下？</li>
</ul>
<p>剧情纯属虚构。真正危险的 AI 不需要你点击确认——它只会让你以为，按钮在你手里。</p>
